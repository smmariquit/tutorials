Sequential

r = float(input("Enter the radius: "))
h = float(input("Enter the height: "))
pi = 3.14
area_circ = pi * r * r
circumference = 2 * pi * r
area_rect = circumference * h
sa_cyl = area_rect + 2 * area_circ
print("The surface area is", sa_cyl)
  • input() returns str. Typecast: int(), float().
  • = assigns, == compares.
  • print(a, b) space-separated. end="" no newline. print() newline.
  • / float division, // integer division, % remainder, ** power.

  • and, or, not. Compare: < <= > >= == !=.
  • Indentation is the block. 4 spaces.

Pattern printing (nested loops)

Recipe: draw n = 4 on paper. Per row i (from 0), count spaces and chars. Find formulas. Outer loop = rows, inner loops = one row, print() ends row.

# filled square n x n
for i in range(n):
    for j in range(n):
        print("X", end="")
    print()

# hollow square
for i in range(n):
    for j in range(n):
        if i == 0 or j == 0 or i == n-1 or j == n-1:
            print("X", end="")
        else:
            print(" ", end="")
    print()

# right triangle, height n
for i in range(n):
    for j in range(i + 1):
        print("*", end="")
    print()
# equilateral (centered) triangle, height n
# row i: spaces = n-1-i, stars = 2i+1
for i in range(n):
    for s in range(n - 1 - i):
        print(" ", end="")
    for k in range(2 * i + 1):
        print("*", end="")
    print()

# same, string repeat shortcut
for i in range(n):
    print(" " * (n-1-i) + "*" * (2*i+1))

Guided problem solutions

A. Divisors, prime (ex. 1, 6)

n = int(input("Enter n: "))
count = 0
for d in range(1, n + 1):
    if n % d == 0:
        print(d)
        count = count + 1
if count == 2:
    print("prime")
else:
    print("composite")

# early exit version
is_prime = n > 1
for d in range(2, n):
    if n % d == 0:
        is_prime = False
        break

Questions to ask: range of candidate divisors (1 to n), test is n % d == 0, counter starts at 0 before the loop, prime has exactly 2 divisors.

See pattern section. Push them to fill the table (spaces, stars per row) before typing. Upside down: reverse the outer range. Extension: box (ex. 11), hollow box, tree (ex. 12).

C. GCF, LCM (ex. 3, 4)

a = int(input("A: "))
b = int(input("B: "))
gcf = 1
for d in range(1, min(a, b) + 1):
    if a % d == 0 and b % d == 0:
        gcf = d          # keeps the biggest
print("GCF:", gcf)

# count-down version with break
d = min(a, b)
while d > 0:
    if a % d == 0 and b % d == 0:
        break
    d = d - 1

# LCM by counting multiples of a
m = a
while m % b != 0:
    m = m + a
print("LCM:", m)
# or: lcm = a * b // gcf
# LCM of three (ex. 5): lcm(lcm(a,b), c)

If they have not seen min(): use an if to pick the smaller.

# 2. count primes between n and 2n (ex. 7)
n = int(input("n: "))
count = 0
for x in range(n, 2 * n + 1):
    if x < 2:
        continue
    is_prime = True
    for d in range(2, x):
        if x % d == 0:
            is_prime = False
            break
    if is_prime:
        count = count + 1
print(count)

Common student errors to watch for

  • Forgetting int() on input, then comparing str to int.
  • Off by one: range(1, n) skips n. range(n) starts at 0.
  • Missing print() after the inner loop, so the whole shape is one line.
  • Update line inside the wrong indentation, or missing, so while never ends.
  • Using = inside if.
  • Resetting the counter inside the loop instead of before it.
